# 云端材料同步设计草案

本文记录需求访谈中的已确认决定及实现前待细化事项，不代表已完成实现。

## 功能定位

云端是按账号保存项目材料的持久化存储库。本地是材料生成与使用的工作环境，由用户选择上传或同步；自动同步仅适用于用户已选择加入同步的项目。各设备独立工作，同步重点是材料复用与并发写入防覆盖，不扩展跨设备任务管理。

## 已确认

- 云端同步的核心对象为项目：一次视频创作或解析任务及其可复用材料。保存链接、图片、状态、字幕、AI 生成材料、封面等，视频本体不上传。
- 支持同一账号多台设备同时登录和同步，至少覆盖三台设备并发使用场景。
- 项目采用唯一 ID、版本及乐观并发控制，避免静默覆盖；并发冲突保留双方版本，详见 [冲突策略](adr/0001-cloud-sync-conflict-policy.md)。
- 首次登录展示本地项目清单，由用户选择哪些项目加入云端；未选择的项目继续仅保存在本机，可随时手动加入。
- 项目加入云端后，该项目后续新增或修改的材料自动同步。
- 登录入口放在设置中的登录区域。
- 新设备登录后自动同步全部项目列表、状态和文字材料；图片、封面等文件在打开对应项目时按需下载，并缓存在本机。
- 提供“下载此项目全部材料”，用于提前准备离线使用；视频本体仍不属于下载范围。
- 同一账号内，识别到同一视频来源时默认复用已有项目，同时允许用户主动创建独立项目。同源不代表两个独立项目必须合并；已有多个候选项目时的选择交互待细化。
- 视频来源优先通过“平台 + 视频 ID”识别，避免链接参数差异造成重复识别；无法可靠识别时的处理待细化。
- 多台设备离线期间各自创建的同源项目，联网后提示关联或合并，保留各自材料，不直接覆盖。
- “清理本机缓存”只释放本机空间，不删除云端项目或影响其他设备；未上传的本地修改不得作为缓存被清除。
- “删除云端项目”向所有设备传播，项目先进入回收站并保留 30 天。
- 其他设备在收到删除时若存在尚未上传的修改，将其保留为可恢复副本并提示处理，不自动重新上传为正常项目。恢复与到期清除的具体交互待细化。
- 各设备独立在本地执行字幕、AI 材料等生成任务；不展示或同步其他设备的执行进度，不提供跨设备任务接管。
- 本地任务进度、运行/失败状态、本地视频路径及缓存状态由设备独立维护；云端同步项目资料与已提交的生成结果。最初所述可同步的“状态”不包含其他设备的任务执行状态，具体业务字段仍待核对。
- 多端并发的重点是同一项目材料上传不互相覆盖，不要求跨设备排队执行生成任务。
- 同类材料存在不同版本时，本机继续使用当前版本，提示云端存在其他版本，由用户主动选择是否切换；新设备首次打开使用云端当前选定的版本。上传新版本本身不自动替换当前使用版本，云端初始版本选定及切换交互仍需细化。

## 实现前待细化

- 同源识别失败、多个候选项目及关联/合并的具体交互。
- 同字段冲突、云端当前版本的选定流程，以及可共享业务状态的具体范围。
- 回收站恢复、到期清除，以及退出登录和账号切换后的本地数据处理。
- 上传下载任务的持久化、并发限制、失败重试和重复提交处理。
- 登录方式、服务部署、存储方案、容量和版本保留策略。
