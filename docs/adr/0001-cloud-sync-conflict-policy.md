# 云端项目同步保留并发冲突版本

同一账号可能在三台设备上同时修改项目。为避免材料被静默覆盖，采用唯一项目 ID、项目版本及乐观并发控制：提交携带基于的版本，版本未改变时接受并生成新版本，版本过期时进入冲突处理，不直接覆盖云端内容。

字幕、AI 文案、封面图等材料发生冲突时保留双方版本，供用户选择；标题、状态等简单字段允许在确认无冲突时按字段合并，同字段并发修改的细则待讨论。上传使用独立任务 ID 和幂等键，防止重试产生重复提交；具体键规则待设计。

用户已确认上述方向，并接受偶尔处理冲突的成本，以换取多端同步中的数据保全。具体合并算法、版本保留周期和冲突界面尚未确定；本决定不代表实现已完成。
